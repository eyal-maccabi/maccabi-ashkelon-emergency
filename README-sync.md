# הגדרת סנכרון מ-Google Sheets — מסך בקרה חירום (PWA)

## מה זה עושה
כשהמסך פתוח ויש רשת, הוא שולף שני טאבים מ-Google Sheets שלך (תפקידים +
ספר טלפונים), שומר אותם במכשיר, ומעדכן את התצוגה. **בלי רשת — ממשיך
לעבוד עם הנתונים האחרונים שנשמרו.** בלי להגדיר כלום — המסך עובד כמו
היום, עם הנתונים הקבועים בקובץ.

## שלב 1 — יצירת הגיליון (פעם אחת, כמה דקות)
1. פתח Google Sheets → גיליון חדש.
2. קרא לטאב הראשון **"תפקידים"**, עמודות בשורה הראשונה: `role,name,phone`
   לדוגמה:
   ```
   role,name,phone
   מנהלת המרחב,שרון בוחבוט,050-6667557
   סגן מנהל המרחב · מנהל המתקן · ממונה הג"א,דניאל גביו,052-6351521
   ```
3. הוסף טאב שני, קרא לו **"ספר טלפונים"**, עמודות: `group,label,phone,notes`
   לדוגמה:
   ```
   group,label,phone,notes
   חירום ורשות מקומית,משטרה,100,
   חירום ורשות מקומית,מד"א,101,
   אחראי יחידות,מ. מעבדה — מירב אלזם,052-3314752,
   ```
   כל השורות עם אותו `group` מתקבצות תחת כותרת אחת במסך, בדיוק כמו היום.

## שלב 2 — פרסום כ-CSV (לכל טאב בנפרד)
בתוך הגיליון: **קובץ ← פרסום לאתר (Publish to web)**
- בחר את הטאב הספציפי (לא "כל הגיליון")
- פורמט: **CSV**
- לחץ "פרסום" → העתק את הקישור שמתקבל (נראה כמו
  `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv`)
- חזור על זה לטאב השני (gid יהיה שונה)

**הערת פרטיות:** "פרסום לאתר" חושף את הטאב לכל מי שמחזיק את הקישור
המדויק (לא מופיע בחיפוש גוגל, לא דורש התחברות) — זו רמת החשיפה שאושרה
לפרויקט הזה, זהה לקובץ ה-HTML הקיים היום. **אם תרצה הרשאות אמיתיות
לפי משתמש Google — זה דורש שינוי ארכיטקטורה (OAuth), לא רק החלפת לינק.**

## שלב 3 — חיבור הלינקים לקובץ
פתח את `pwa/emergency-dashboard.html`, חפש את `SYNC_URLS` (קרוב לסוף
הקוד), והדבק את שני הלינקים:
```js
const SYNC_URLS = {
  roles: "https://docs.google.com/spreadsheets/d/e/.../pub?gid=0&single=true&output=csv",
  phonebook: "https://docs.google.com/spreadsheets/d/e/.../pub?gid=123456&single=true&output=csv",
};
```
שמור. מרגע זה, כל פתיחה עם רשת תשלוף את הגרסה העדכנית.

## מה לא מסתנכרן (עדיין)
רק תפקידים + ספר טלפונים. צ'קליסטים, קומות, תרחישים וסדר הפעולות
נשארים קבועים בקוד — הם משתנים לעתים רחוקות, ואם תרצה להוסיף גם
אותם לסנכרון, זה אותו תבנית (CSV נוסף + פונקציית apply דומה).

## עדכון שוטף
כשאתה (או אולגה, אם יש לה גישת כתיבה לגיליון) מעדכן מספר טלפון בגיליון
— כל מכשיר שפתוח עם רשת מקבל את זה בפתיחה הבאה (או בלחיצה על "סנכרן
עכשיו"). אין צורך לגעת בקוד שוב.
